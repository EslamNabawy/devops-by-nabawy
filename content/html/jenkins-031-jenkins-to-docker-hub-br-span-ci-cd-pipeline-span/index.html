Milestone 01 — Foundation

Why this roadmap exists

Every commit should produce a versioned, push-ready image without manual steps. This roadmap stitches Git → Jenkins → Docker → Docker Hub into a single observable path with secure credentials and automatic cleanup.

You will ship

yourusername/myapp:build-<N> + :latest — authenticated via Jenkins credentials, cleaned after each run. No tokens in Git, no passwords in logs.

⚠
Golden rule — never hardcode secrets

Use Manage Jenkins → Credentials and inject with credentials('dockerhub-credentials'). The roadmap fails safely if ID mismatches.

Milestone 03 — Pipeline as Code Core of the roadmap

Jenkinsfile — the roadmap in code

Place at repo root. Declarative syntax — Jenkins validates every stage before the first run.

▦ Jenkinsfile JENKINSFILE
GROOVY 
pipeline {
    agent any
    environment {
        DOCKERHUB_CREDENTIALS = credentials('dockerhub-credentials')
        DOCKER_IMAGE = "yourusername/myapp" // ← your Docker Hub repo
        IMAGE_TAG = "build-${BUILD_NUMBER}"
    }
    stages {
        stage('Checkout Repo') { steps { checkout scm } }
        stage('Build Docker Image') { steps { script {
            sh "docker build -t ${DOCKER_IMAGE}:${IMAGE_TAG} ." } } }
        stage('Login to Docker Hub') { steps { script {
            sh "echo \$DOCKERHUB_CREDENTIALS_PSW | docker login -u \$DOCKERHUB_CREDENTIALS_USR --password-stdin" } } }
        stage('Push Image') { steps { script {
            sh "docker push ${DOCKER_IMAGE}:${IMAGE_TAG}"
            sh "docker tag ${DOCKER_IMAGE}:${IMAGE_TAG} ${DOCKER_IMAGE}:latest"
            sh "docker push ${DOCKER_IMAGE}:latest" } } }
    }
    post { always { sh "docker rmi ${DOCKER_IMAGE}:${IMAGE_TAG} || true"; sh "docker logout" } }
}
🔐 ENVInjects USR/PSW — masked in logs.
🏷️ TAGbuild-${BUILD_NUMBER} = immutable history.
🔑 LOGIN--password-stdin hides token from ps.
🧹 POSTClean + logout — keeps agents lean.
