Chapter 05 · Idempotency

⚖️ MODULES & IDEMPOTENCY

ADV

Same input twice → same end state. Second run ok, not changed.

First Run — Changed
Desired: nginx present ↓ Current: absent ↓ Install → ◐ CHANGED
Second Run — OK
Desired: nginx present ↓ Current: present ↓ No action → ● OK
$ ansible-playbook -i inventory.ini idempotent.yml TASK [Create app directory] **** changed: [web-01] $ ansible-playbook -i inventory.ini idempotent.yml TASK [Create app directory] **** ok: [web-01]
Failed→"OK" ≠ did nothing — it means already correct. Read ok vs changed.
